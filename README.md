# Rhythms of Global Greening

This repository contains the full workflow used to reproduce the analyses presented in the manuscript **“Rhythms of Global Greening.”**  
It includes data preprocessing, time-series resampling, wavelet analysis, and figure generation.

## Repository Structure

### Directories

- **`wavelets_wrapper/`**  
  Contains custom wavelet functions used throughout the analysis.

- **`gmt-palettes/`**  
  Color palette (`.cpt`) files used for plotting with **PyGMT**.

- **`site_wavelet_plots/`**  
  Output figures for **Site 1–5** as described in the manuscript.  
  Figures are generated by `individual-site-wavelet-analysis.ipynb`.

- **`sliced_csvs/`**  
  Contains split CSV files with pixel centroid coordinates.  
  These files are generated using `pixel_centers.ipynb`.

---

### Notebooks

- **`hdf-read.ipynb`**  
  Converts raw Earthdata HDF files into NetCDF format and produces a single NetCDF file containing only complete EVI time series.

- **`resample_evi_16_days_nearest.ipynb`**  
  Resamples EVI time series to a regular 16-day interval using nearest-neighbour interpolation.

- **`pixel_centers.ipynb`**  
  Extracts pixel centroid coordinates from the NetCDF file, retaining only pixels with complete (non-NaN) time series.

- **`individual-site-wavelet-analysis.ipynb`**  
  Demonstrates wavelet analysis for selected sites (Site 1–5) used in the manuscript.

---

### Scripts

- **`power-analysis-timeseries-complete-scales_windows.py`**  
  Runs wavelet analysis for each latitude–longitude coordinate listed in the pixel centroid CSV files.

- **`submit-complete-scales_windows.sh`**  
  Example HPC submission script for running the wavelet analysis in parallel.

- **`utils.py`**  
  Utility functions used by `power-analysis-timeseries-complete-scales_windows.py`.
